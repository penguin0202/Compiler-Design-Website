Growing up, I was always confused on how writing in what essentially is a text file could make computers do things. In C, running "int c = 1;" seemingly magically makes the computer store the value of 1 somewhere on the machine; in Python, running "print(12345)" displays the number 12345 in the console, almost as if the computer understood the meaning of "print"-ing text. What I knew then was that computers store and operate on things in ones and zeroes, on and off switches, and what anybody typed in a programming script was certainly neither of those things,and that computers certainly did not have the "intelligence" to comprehend English. So how do computers actually know what to do and well, do them, when given a script in any particular programming language?

When a file is created on a computer, either by you or a program, its name usually ends with a file extension (e.g. ".docx" for Word documents, ".png" for P.N.G. images). But what exactly do the extensions do? Well, file extensions help the Operating System (like Microsoft's Windows or Apple's MacBook) identify how to open a file. Take ".docx" for example: when you open a file ending in the extension, the Operating System (O.S.; more on it in later sections) searches through its catalog of programs to find one that is designed to open a .docx document, then it calls the program to open it (in this case, Microsoft Word). If extensions had not existed, the computer would have no idea how to differentiate between image files like .pngs and executable files like .exe, thus making it hard to do anything on a computer that involves files (which are a lot of things). This idea of extensions can be extended to programming scripts as well (see what I did there?). When opening a, let's say, C language file, the O.S. can open it in two ways. It can either open the script in a text/code editor program like Notepad or Visual Studio Code to allow users to edit it, or it can open the file, per the user's request, in a program that can "run" the file (which is the end goal of a script duh). That program is called a "compiler". I will backtrack and refine this in the following section, but for now this is all you need to know: a compiler is a program that allows code in a file to be executed on a computer.
