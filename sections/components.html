Programming language is the standard. Compiler is its implementation first we look at not the words in a programming language, but the (white)spaces. Like in natural languages, we need a way to separate words/concepts, and whitespace is the best way to do that. e.g. "int myVariable = 5;" in c++ is different from "intmyVariable = 5;"; the former declares an integer variable called myVariable and initializes it to 5, while the latter assigns the value of 5 to an existing variable, presumably an integer, named "intmyVariable" but you may notice that some "things" don't need spaces to differentiate itself from other parts/components of the language, like semicolons an commas. Same in writing, things that represent concepts, like datatypes and names, are already in letters, and will never be in special symbols (though one can create their own programming language to change this established/standard rule), so anytime a symbol appears, it will never be assumeed to be a part of the previous set of characters, thus no need for white spaces datatypes, names, all need letters as identifiers
